Begonnen met deze site

1 september 2026

Ik ben deze week begonnen aan mijn portfolio site. eerst had ik alleen een index.html met wat tekst erin en verder niks. Ik wist eigenlijk niet zo goed waar ik moest beginnen dus ben ik eerst wat filmpjes op youtube gaan kijken over html en css. dat hielp wel want ik snapte daarna beter hoe de structuur van een pagina in elkaar zit.

Semantische elementen

3 september 2026

Ik heb geleerd dat je niet zomaar overal hetzelfde element voor moet gebruiken. Voor de bovenkant van de pagina gebruik je header, voor het menu nav, voor de inhoud main en onderaan footer. Voor losse stukjes zoals een blogpost gebruik je article. Ik had eerst overal section staan maar dat is meer voor een onderdeel van een pagina, en article is voor iets wat op zichzelf staat. Ook heb ik geleerd dat je menu eigenlijk een lijstje is, dus ul met li erin, en de links daar tussenin.

CSS koppelen en dat het niet werkte

4 september 2026

Toen ik css ging toevoegen werkte het eerst niet. Ik had een kleur gezet op h2 maar ik zag niks veranderen. na wat zoeken bleek dat mijn browser nog de oude versie liet zien, dus met ctrl shift r moest ik hem opnieuw laden. daarna werkte het wel. Ik heb ook geleerd dat je goed moet kijken naar het pad in de link tag, want als je css bestand in een andere map staat dan klopt het pad niet meer.

Responsive maken

4 september 2026

Het laatste wat ik heb gedaan is de site responsive maken. Dat doe je met media queries, dat is eigenlijk een soort if statement in css. Je zegt dan vanaf een bepaalde breedte moet de layout er anders uitzien. Ik heb het getest met f12 in de browser op 480, 768 en 1024 pixels. Bij mobiel staat alles onder elkaar en op een breder scherm naast elkaar.
